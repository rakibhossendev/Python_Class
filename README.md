## Class 2 (Python Basic)

### Variable

```python
variableName = value
```

### What is a variable?
- A variable is a named container in memory that stores a value. The value stored in it can change, vary, or be replaced with a different value later.

### Variable Naming Rules
- Spaces are not allowed: `my number` -> not allowed (use `my_number` or `myNumber`)
- Special symbols are not allowed: `@`, `$`, `#`, `&`, `/`, etc. -> not allowed
- Cannot start with a digit: `1name` -> not allowed. A variable name must begin with a letter (`a-z`, `A-Z`) or an underscore (`_`)
- Variable names are case-sensitive: `age` and `Age` are two different variables
- Reserved keywords cannot be used as a variable name: `if`, `for`, `class`, `def`, etc.

### Meaningful Names
- `x`, `y`, `z`, `a`, `c` -> avoid single-letter or unclear names; use names that describe what they store
- `my_name` -> Snake Case
- `myName` -> Camel Case
- `MyName` -> Pascal Case

### Naming Conventions
- **Snake Case** -> all lowercase words separated by underscores (`my_name`) - used for variables and functions
- **Camel Case** -> first word lowercase, following words capitalized (`myName`) - used for variables in many languages
- **Pascal Case** -> every word capitalized (`MyName`) - used for class names

## Data Type
- **integer** -> whole numbers, positive or negative, with no decimal point. Example: `1, 2, 4`
- **float** -> numbers with a decimal point (non-whole numbers). Example: `12.10`
- **boolean** -> only two values: `True` or `False`. Example: `True`, `False`
